## Live site (checked 22 Nov 2026 through a reader proxy, since this machine's network resets TLS to the domain)

1. **Old build still live.** The homepage still shows Palaniappan and 98405 01323. Nothing changes in search until the new build is deployed.
2. **www / non-www mismatch.** `https://visalatchimanufacturing.com/about` redirects to `https://www.visalatchimanufacturing.com/about`, but the page's canonical, the sitemap and all schema `@id`s use the non-www URL. Google then sees every canonical pointing at a URL that redirects away. Fix in Vercel: Project > Settings > Domains, make `visalatchimanufacturing.com` the primary domain and set `www` to redirect to it (no code change needed).
3. `/packaging-glossary` returns the 404 page (expected: it is new in this branch).
